# bluestacks

Эта версия Bluestacks для floweringdlc.pro обеспечивает ЛУЧШУЮ производительность. туториал ниже

#ТУТОРИАЛ

1. Установите блюстакс
2. Зайдите в менеджер окон блюстакс
3. Нажмите новое окно в правом нижнем углу
4. Выберете: Новое (новый аккаунт) 
5. Выбрать версию Android: Nougat 32-bit (Large virtual address) - Deprecated 
6. Запустите это окно которое создали, можно играть. 

ADB - не нужен
